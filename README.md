# 🎧 Sonora | Premium Headphones Website

A modern, responsive headphones website built with **HTML, CSS, and JavaScript**.

This project focuses on creating a premium and immersive user experience with a dark aesthetic, gold accents, smooth interactions, and responsive layouts across different screen sizes.

## ✨ Features

* 🎧 Modern premium headphones UI
* 📱 Fully responsive design
* 🧭 Reusable navigation bar
* 📂 Multiple pages:

  * Home
  * Shop
  * Collections
  * Accessories
  * About
  * Support
* 📱 Responsive mobile navigation menu
* ✨ Interactive hover effects
* 🖼️ Product and collection sections
* 🎨 Custom styling with CSS
* ⚡ JavaScript-powered interactions

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
